Custom characters shared with everyone on this server.

Put each model folder in entries/. A model folder is named by its 64-character
id and contains manifest.json, character.glb and preview.png, exactly as the
Windows build's importer creates them in
%LOCALAPPDATA%\Skate3RustEngine\custom-characters\entries.

They appear in game under CREATE > Custom Models > Show: Imported within 30
seconds. The server log says if a folder is skipped and why.
